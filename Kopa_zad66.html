Pseudoelement :first-line

Pseudoelement :first-line pozwala formatować tylko pierwszy wiersz tekstu znajdującego się w akapicie lub innym elemencie blokowym. Można zmieniać między innymi kolor, rodzaj i wielkość czcionki.

Przykład:

:first-line
{
  color:red;
  font-weight:bold;
}

Pseudoelementy :before oraz :after

Pseudoelement :before służy do wstawiania treści przed zawartością elementu, natomiast :after służy do wstawiania treści po zawartości elementu. Do działania wymagają właściwości content.

Przykład:

p:before
{
  content:"*** ";
}

p:after
{
  content:" ***";
}

Pseudoelement :first-letter

Pseudoelement :first-letter pozwala formatować pierwszą literę akapitu. Jest często wykorzystywany do tworzenia ozdobnych inicjałów.

Przykład:

:first-letter
{
  font-size:40pt;
  color:green;
}
